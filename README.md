# aus10powell.github.io

Personal site and blog, published with GitHub Pages at [aus10powell.github.io](https://aus10powell.github.io). Built with Jekyll on the [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) theme (theme sources vendored in `_includes`, `_layouts`, `_sass` and `assets`).

## Running locally

```bash
bundle install
bundle exec jekyll serve
```

The site is then available at <http://127.0.0.1:4000>.

## Layout

- `_posts/` — blog posts, including the yearly technical reading lists (`YYYY-01-01-Reading.markdown`)
- `_pages/` — standalone pages (About, Posts index)
- `_data/navigation.yml` — masthead navigation
- `_config.yml` — site-wide Jekyll and theme settings
